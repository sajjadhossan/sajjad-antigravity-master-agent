# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 8.0.x   | :white_check_mark: |
| < 8.0.0 | :x:                |

## Reporting a Vulnerability

Security of developer workstations and release pipelines is our highest priority.
If you discover a security vulnerability within Antigravity Master Agent:

1. **Do NOT** open a public GitHub issue.
2. Email security details privately to: `security@antigravity.dev`.
3. Provide a reproduction script, affected versions, and potential impact.
4. Our team will acknowledge receipt within 24 hours and issue a patch advisory within 72 hours.
