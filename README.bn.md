**VS Code এবং Google Antigravity IDE-এর জন্য একটি আন্তর্জাতিক মানের ৫০-ইন-১ এন্টারপ্রাইজ ডেভেলপার সুইট — রচয়িতা: সাজ্জাদ হোসাইন।**

---

## 🌟 প্রধান সুবিধাসমূহ

- **🏛️ ৫টি এন্টারপ্রাইজ স্তম্ভ ও লাইভ স্বাস্থ্য স্কোর (০–১০০%)**:
  সিকিউরিটি, ডেভঅপ্স, কোড কোয়ালিটি, ডেটা সেফটি এবং আর্কিটেকচার কমপ্লায়েন্স নিশ্চিতকরণ।
- **📂 নেটিভ সাইডবার ৫-পিলার এক্সপ্লোরার (Activity Bar Tree View)**:
  কোড এডিটর থেকে সরাসরি glanceable স্ট্যাটাস আইকন (`pass-filled`, `warning`, `error`, `clock`) এবং ১-ক্লিকে কুইক অ্যাকশন।
- **🖥️ আধুনিক ৪-ট্যাব কমান্ড সেন্টার ড্যাশবোর্ড**:
  বৃত্তাকার এসভিজি কমপ্লায়েন্স মিটার, ৫০টি মডিউলের অ্যাকর্ডিয়ন গ্রুপিং, ডেভঅপ্স রানার এবং কাস্টম রুলস ম্যানেজার।
- **✨ ১-ক্লিক অটো-হিল ইঞ্জিন (Auto-Heal Engine)**:
  অনুপস্থিত রুলস, মেমোরি ব্যাংক, সিকিউরিটি প্যাটার্ন এবং সিআই/সিডি ওয়ার্কফ্লো এক ক্লিকে সমাধান করে ১০০% স্বাস্থ্য স্কোর নিশ্চিত করে।
- **💡 লাইটবাল্ব কুইক-ফিক্স কোড অ্যাকশন (`Ctrl+.`)**:
  ফাঁকা বাটন হ্যান্ডলার, সিক্রেট ফাইল লিক, আনপিন্ড ডিপেনডেন্সি এবং মিসিং `tenant_id` কোয়েরির তাত্ক্ষণিক সমাধান।
- **🔍 ক্রস-প্ল্যাটফর্ম DTO ও স্কিমা প্যারিটি গার্ড**:
  Prisma, SQL DDL, Dart মডেল এবং TypeScript ইন্টারফেসের ফিল্ড ও টাইপ স্বয়ংক্রিয়ভাবে সিঙ্ক রাখে।
- **💾 রিয়েল জিরো-ডেমো ব্যাকআপ ও রিস্টোর ইঞ্জিন**:
  GZIP কম্প্রেশন, SHA-256 চেকার এবং ডাটাবেজ রিস্টোর ভ্যালিডেশন টেস্ট।
- **📱 অ্যান্ড্রয়েড APK প্রি-ফ্লাইট ও কিউআর ডেলিভারি**:
  পারমিশন ও সাইনিং কি ভ্যালিডেশন এবং সরাসরি মোবাইল থেকে টেস্টের জন্য রিলিজ APK কিউআর কোড জেনারেটর।
- **🚀 প্রোডাকশন-রেডি CI/CD ওয়ার্কফ্লো জেনারেটর**:
  অ্যান্ড্রয়েড রিলিজ, ভার্সেল ওয়েব ডেপ্লয়মেন্ট, উইন্ডোজ ও ম্যাকওএস ডেস্কটপ প্যাকেজিং পাইপলাইন তৈরি করে।
- **🌐 সম্পূর্ণ বাংলা ও ইংরেজি সমর্থন**:
  সকল নোটিফিকেশন, লগ ও ড্যাশবোর্ডে শতভাগ দ্বিভাষিক ইন্টারফেস।

## 📦 ইনস্টলেশন পদ্ধতি

### লোকাল VSIX প্যাকেজ থেকে:
```bash
code --install-extension ./sajjad-antigravity-master-agent-8.1.0.vsix
```

### ইন্টিগ্রিটি যাচাইকরণ:
```powershell
Get-FileHash -Algorithm SHA256 .\sajjad-antigravity-master-agent-8.1.0.vsix
```
